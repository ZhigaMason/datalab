# ENTSO-E

This project is an end-to-end pipeline to inspect and predict power consumptaion and renewable energy generation in Europe. The data is taken from [ENTSO-E Transperency platform](https://www.entsoe.eu/), processed by a PySpark ETL pipeline and visualized using Plotly Dash. Predictions are made using XGBoost model. The whole project is hosted on MS Azure.
